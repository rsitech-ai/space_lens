# Security Policy

## Supported versions

Before the first public release, security fixes target the current `main`
branch. After a 1.x release, the latest 1.x version will receive fixes; older
versions may be asked to upgrade.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub private vulnerability reporting when it is enabled for this
repository. Otherwise email [info@rsitech.ai](mailto:info@rsitech.ai?subject=SpaceLens%20security%20report)
with the subject `SpaceLens security report`. Include affected versions,
reproduction steps, impact, and suggested mitigations. Remove unrelated private
file paths, file contents, credentials, and personal data.

You should receive an acknowledgement within five business days. The project
will coordinate validation, remediation, and disclosure timing with the
reporter. Please allow a reasonable remediation window before public disclosure.

## Release status

No formal security scan is represented by this policy. The open-source
readiness record documents which verification was and was not performed for
each release candidate.
